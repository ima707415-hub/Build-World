# BuildWorld: Create your own world

An Android-first survival sandbox project made with Godot 4.

## Current prototype
- 2D top-down project setup
- Procedurally generated placeholder terrain
- Player movement using Godot's built-in directional input actions
- Camera follows the player

## Planned for v1.0
- World creation and exploration
- Resources and gathering
- Three mobs: rabbit, boar, and slime
- Tools, inventory, and crafting
- Local world saves

This is an early starter project, not a finished game. Features in the roadmap are not implemented yet.

## Open in Godot
Open the project folder and select `project.godot`.
Main scene: `scenes/Main.tscn`.
